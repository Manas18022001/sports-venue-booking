# Visual assets

## Original decorative court photograph

- Saved project asset: [turfit-courts.png](../apps/web/public/images/turfit-courts.png).
- Generated using the built-in image generation tool, not the CLI fallback.
- Used only as decorative hero imagery. It does not represent a listed venue.
- Original generated output was copied into the project; no external generated-image path is required at runtime.

Generation prompt:

> Use case: photorealistic-natural. Asset: original editorial hero photograph for Turfit, a refined sports court booking web application. Create a high-resolution landscape photograph, 3:2 aspect ratio, oblique aerial view of beautiful outdoor tennis courts with forest green playing surfaces and muted terracotta runoffs, crisp realistically correct white tennis court lines and a real net, surrounded by lush mature trees. Golden late-afternoon sunlight and long natural shadows. A very small pair of anonymous adult players in white at opposite baselines adds scale. Premium architectural travel photography, authentic surface texture, soft film grain, restrained colors, warm natural light, visually inviting, composition dominated by the geometric court. No text, no lettering, no logos, no watermark, no UI, no collage. This is decorative sports imagery, not a depiction of any named real venue.
